[app.gameforsmart.com](https://app.gameforsmart.com) adalah pusat kendali utama GameForSmart. Di sini kamu bisa mengelola quiz, memantau riwayat permainan, melihat evaluasi, serta mengatur pertemanan dan grup.
 
---
 
## Menu Utama
 
Semua fitur dapat diakses dari sidebar di sebelah kiri:
 
| Menu | Fungsi |
|------|--------|
| [Dashboard](/docs/app/dashboard) | Ringkasan aktivitas, statistik cepat, dan shortcut |
| [Quiz](/docs/app/quiz) | Jelajahi, buat, dan kelola quiz |
| [Friends](/docs/akun/friends) | Kelola pertemanan — following, follower, dan pencarian |
| [Groups](/docs/akun/groups) | Buat dan kelola grup bermain |
| [History](/docs/app/history) | Riwayat semua sesi sebagai host maupun player |
| [Evaluation](/docs/app/evaluation) | Analisis performa bermainmu secara keseluruhan |
 
<Callout type="info">
  Menu Friends dan Groups dibahas lengkap di bagian [Akun](/docs/akun/friends).
</Callout>
