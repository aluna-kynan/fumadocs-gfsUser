Notifikasi di GameForSmart diterima melalui ikon lonceng di pojok kanan atas [app.gameforsmart.com](https://app.gameforsmart.com). Pastikan kamu membuka app.gameforsmart.com untuk menerima notifikasi secara real-time.

---

## Jenis Notifikasi

### Invite Sesi Game

Dikirim oleh host (owner atau admin grup, maupun teman yang kamu follow mutual) saat mereka membuat sesi game dan mengundangmu untuk bergabung.

Cara menerima:
1. Buka [app.gameforsmart.com](https://app.gameforsmart.com)
2. Klik ikon lonceng di pojok kanan atas
3. Temukan notifikasi invite sesi
4. Klik **Accept** untuk bergabung ke sesi

<Callout type="info">
  Notifikasi invite sesi hanya muncul di app.gameforsmart.com, bukan di halaman game langsung. Pastikan tab app.gameforsmart.com tetap terbuka agar tidak melewatkan invite.
</Callout>

### Invite Grup

Dikirim oleh owner atau admin grup saat mereka mengundangmu bergabung ke sebuah grup (khusus grup bertipe **Secret**).

Cara menerima:
1. Buka [app.gameforsmart.com](https://app.gameforsmart.com)
2. Klik ikon lonceng di pojok kanan atas
3. Temukan notifikasi invite grup
4. Klik **Accept** untuk bergabung ke grup

<Callout type="tip">
  Setelah bergabung ke grup, kamu akan otomatis menerima notifikasi invite sesi game dari owner dan admin grup tersebut di masa mendatang.
</Callout>
