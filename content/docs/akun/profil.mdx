## Daftar Akun

<Tabs items={['Daftar via Google', 'Daftar Manual']}>

<Tab value="Daftar via Google">

<Steps>

<Step>

### Buka halaman Sign Up

Buka [app.gameforsmart.com](https://app.gameforsmart.com) dan klik **Sign up**.

</Step>

<Step>

### Klik Login dengan Google

Klik tombol **Google** di bagian atas formulir.

</Step>

<Step>

### Pilih akun Google

Pilih akun Google yang ingin digunakan — kamu akan langsung masuk tanpa perlu mengisi formulir tambahan.

</Step>

</Steps>

</Tab>

<Tab value="Daftar Manual">

<Steps>

<Step>

### Buka halaman Sign Up

Buka [app.gameforsmart.com](https://app.gameforsmart.com) dan klik **Sign up**.

</Step>

<Step>

### Isi formulir pendaftaran

Lengkapi semua kolom berikut:

- **Full Name** — nama lengkapmu
- **Username** — nama unik yang digunakan untuk login dan tampil ke pemain lain
- **Country, State, City** — lokasi domisilimu (bisa menggunakan tombol **Deteksi Lokasi Otomatis**)
- **Email** — alamat email aktif
- **Password** — kata sandi akunmu

<Callout type="info">
  Username bersifat unik — jika sudah dipakai orang lain, kamu akan mendapat pesan "Username is already taken". Coba username lain.
</Callout>

</Step>

<Step>

### Klik Register

Setelah semua kolom terisi, klik tombol **Register** untuk menyelesaikan pendaftaran.

</Step>

</Steps>

</Tab>

</Tabs>

## Login

<Tabs items={['Login via Google', 'Login via Username / Email']}>

<Tab value="Login via Google">

1. Buka halaman login game atau [app.gameforsmart.com](https://app.gameforsmart.com)
2. Klik tombol **Google**
3. Pilih akun Google yang terdaftar — kamu langsung masuk

</Tab>

<Tab value="Login via Username / Email">

1. Buka halaman login game atau [app.gameforsmart.com](https://app.gameforsmart.com)
2. Masukkan **Email atau Username** di kolom pertama
3. Masukkan **Password**
4. Klik **Login**

Lupa password? Klik tautan **Forgot your password?** untuk mereset password melalui email.

</Tab>

</Tabs>

## Edit Profil

Untuk mengubah informasi profil, buka [app.gameforsmart.com/profile](https://app.gameforsmart.com/profile).

### Informasi yang bisa diubah

| Kolom | Keterangan |
|-------|-----------|
| Foto profil | Klik ikon kamera pada avatar untuk mengganti foto |
| Full Name | Nama lengkap |
| Nickname | Nama panggilan yang ditampilkan |
| Username | Nama unik untuk login |
| Email | Tidak dapat diubah jika login via Google |
| Phone Number | Nomor telepon (opsional) |
| Date of Birth | Tanggal lahir |
| Grade | Jenjang pendidikan |
| Organization / Institution | Sekolah, kampus, atau institusi |
| Gender | Jenis kelamin |
| Country, State, City | Lokasi domisili |

Setelah selesai mengubah, klik **Save Changes** untuk menyimpan. Klik **Cancel** untuk membatalkan perubahan.

<Callout type="tip">
  Pastikan username dan foto profil sudah diisi — keduanya akan tampil ke pemain lain saat sesi game berlangsung.
</Callout>
