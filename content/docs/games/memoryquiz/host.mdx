Sebagai host, kamu bertugas membuat sesi, memilih kuis, membagikan room code ke peserta, dan memulai game.

---

## Membuat Sesi

<Steps>

<Step>

### Buka MemoryQuiz

Buka [memoryquiz.gameforsmart.com](https://memoryquiz.gameforsmart.com) dan pastikan sudah login dengan akun GameForSmart.

</Step>

<Step>

### Klik Create Game

Di halaman utama, klik tombol **CREATE GAME** untuk membuat room baru.

</Step>

<Step>

### Pilih Quiz

Kamu akan diarahkan ke halaman **Select Quiz**. Temukan quiz yang ingin digunakan:

- Gunakan kolom **Search** untuk mencari kuis berdasarkan judul.
- Setelah ketemu, klik **Select** pada kuis tersebut.

</Step>

<Step>

### Bagikan Room Code ke Peserta

Setelah kuis dipilih, kamu akan masuk ke halaman Lobby. Di sini, akan muncul **Room Code** (contoh: `123456`).
Bagikan kode ini kepada para peserta agar mereka bisa bergabung.

</Step>

<Step>

### Mulai Sesi

Tunggu hingga semua peserta masuk ke dalam Lobby. Jika semua sudah siap, klik **START GAME** untuk memulai kuis.

</Step>

</Steps>

---

## Memantau Sesi (Saat Game Berlangsung)

Saat game berjalan, layar Host akan menampilkan **Live Leaderboard** yang diperbarui secara real-time. Kamu bisa melihat siapa yang memiliki memori paling tajam dan menjawab dengan benar!
