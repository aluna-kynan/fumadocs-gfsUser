Sebagai host, kamu bertugas membuat sesi, memilih quiz, mengatur sesi, membagikan room code ke peserta, dan memulai game.

---

## Membuat Sesi

<Steps>

<Step>

### Buka MemoryQuiz

Buka [memoryquiz.gameforsmart.com](https://memoryquiz.gameforsmart.com) dan pastikan sudah login dengan akun GameForSmart.

</Step>

<Step>

### Klik Host Game

Di halaman utama, klik tombol **HOST** untuk membuat sesi baru.

</Step>

<Step>

### Pilih Quiz

Kamu akan diarahkan ke halaman **Select Quiz**. Temukan quiz yang ingin digunakan:

- Gunakan kolom **Search Quiz...** untuk mencari berdasarkan judul
- Gunakan filter **All** untuk menyaring berdasarkan kategori
- Klik ikon ❤️ untuk menyimpan quiz ke Favorit
- Klik ikon **My Quizzes** di pojok kanan atas untuk melihat quiz buatanmu sendiri — quiz dibuat melalui [app.gameforsmart.com](https://app.gameforsmart.com), lihat panduannya di [halaman Quiz](/docs/app/quiz)

Klik kartu quiz yang diinginkan untuk memilihnya.

</Step>

<Step>

### Atur Pengaturan Sesi

Setelah memilih quiz, muncul halaman pengaturan sesi:

| Pengaturan | Keterangan |
|-----------|-----------|
| **Duration** | Batas waktu total sesi (contoh: 5 Min) |
| **Questions** | Jumlah soal yang akan dimainkan |
| **Difficulty** | **Easy** (12 kartu) · **Medium** (16 kartu) · **Hard** (20 kartu) |

Setelah selesai, klik **CREATE ROOM** untuk masuk ke lobby. Klik **Back** untuk kembali ke halaman pemilihan quiz.

</Step>

<Step>

### Bagikan Room Code ke Peserta

Di halaman lobby host terdapat:

- **Room Code** — kode 6 digit yang bisa disalin
- **QR Code** — bisa di-scan peserta langsung dari perangkat mereka
- **Link Join** — contoh: `https://memoryquiz.gameforsmart.com/player/447802/waiting`
- **Invite Groups** — kirim invite langsung ke seluruh anggota grupmu
- **Invite Friends** — kirim invite langsung ke teman yang kamu follow

Di sisi kanan lobby terlihat semua player yang sudah bergabung beserta avatar mereka, beserta info **durasi** dan **jumlah soal** sesi di bagian atas.

<Callout type="tip">
  Gunakan **Invite Groups** atau **Invite Friends** untuk mengundang langsung tanpa perlu membagikan room code secara manual.
</Callout>

</Step>

<Step>

### Mulai Sesi

Setelah semua peserta siap, klik **START** untuk memulai game. Klik **EXIT** untuk membatalkan sesi sebelum dimulai.

</Step>

</Steps>

---

## Monitor Sesi (Saat Game Berlangsung)

Setelah sesi dimulai, host masuk ke halaman **monitor** yang menampilkan semua player secara real-time:

- **Jumlah player** ditampilkan di pojok kiri atas
- **Timer countdown** — menunjukkan sisa waktu sesi
- Setiap kartu player menampilkan **nama**, **avatar**, dan **progress**
- Label **GAME** menunjukkan player sedang dalam fase memory, label **QUIZ** menunjukkan player sedang mengerjakan soal

Klik tombol **AKHIRI** untuk mengakhiri sesi lebih awal.

<Callout type="info">
  Host tidak ikut bermain di halaman monitor — halaman ini hanya untuk memantau progress seluruh player secara real-time.
</Callout>

---

## Halaman Result Host

Setelah sesi selesai, host melihat halaman **leaderboard** yang menampilkan:

- **Podium juara** — kartu besar untuk pemain peringkat teratas
- **Tabel lengkap** — kolom Juara, Pemain, Skor, dan Waktu untuk seluruh peserta

| Tombol | Fungsi |
|--------|--------|
| **Beranda** | Kembali ke halaman utama MemoryQuiz |
| **Mulai Ulang** | Jalankan ulang sesi dengan quiz yang sama |
| **Statistik** | Buka halaman statistik detail di [app.gameforsmart.com](https://app.gameforsmart.com) |
