Sebagai host, kamu bertugas membuat sesi, memilih kuis, membagikan room code ke peserta, dan mengontrol ritme pertandingan berkecepatan tinggi ini.

---

## Membuat Sesi

<Steps>

<Step>

### Buka NitroQuiz

Buka [nitroquiz.gameforsmart.com](https://nitroquiz.gameforsmart.com) dan pastikan sudah login dengan akun GameForSmart.

</Step>

<Step>

### Klik Create Game

Di halaman utama, klik tombol **CREATE GAME** untuk membuat room baru.

</Step>

<Step>

### Pilih Quiz

Kamu akan diarahkan ke halaman **Select Quiz**. Temukan quiz yang ingin digunakan:

- Gunakan kolom **Search** untuk mencari kuis berdasarkan judul.
- Setelah ketemu, klik **Select** pada kuis tersebut.

</Step>

<Step>

### Bagikan Room Code ke Peserta

Setelah kuis dipilih, kamu akan masuk ke halaman Lobby. Di sini, akan muncul **Room Code** (contoh: `123456`).
Bagikan kode ini kepada para peserta agar mereka bisa bergabung.

</Step>

<Step>

### Mulai Sesi

Tunggu hingga semua peserta masuk ke dalam Lobby. Jika semua sudah siap, klik **START GAME** untuk memulai pertarungan Nitro.

</Step>

</Steps>

---

## Memantau Sesi (Saat Game Berlangsung)

Berbeda dengan kuis santai, layar Host di NitroQuiz dioptimalkan untuk menunjukkan perubahan posisi (Rankings) secara dramatis dan *real-time*. Host dapat memandu acara dan memberikan komentar layaknya komentator balap sembari para pemain berlomba memberikan jawaban tercepat!
