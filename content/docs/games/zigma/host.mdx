Sebagai host (atau *Dungeon Master*), kamu bertugas membuat sesi petualangan, memilih kuis, membagikan room code ke party, dan mengelola jalannya pertempuran.

---

## Membuat Sesi

<Steps>

<Step>

### Buka Zigma

Buka [zigma.gameforsmart.com](https://zigma.gameforsmart.com) dan pastikan sudah login dengan akun GameForSmart.

</Step>

<Step>

### Klik Create Game (Dungeon)

Di halaman utama, klik tombol **CREATE GAME** untuk membuat ruang petualangan baru.

</Step>

<Step>

### Pilih Quiz

Kamu akan diarahkan ke halaman **Select Quiz**. Temukan quiz yang ingin digunakan:

- Gunakan kolom **Search** untuk mencari kuis berdasarkan judul.
- Setelah ketemu, klik **Select** pada kuis tersebut. Kuis ini akan berfungsi sebagai "serangan" pemain terhadap monster.

</Step>

<Step>

### Bagikan Room Code ke Peserta

Setelah kuis dipilih, kamu akan masuk ke halaman Lobby (Tavern). Di sini, akan muncul **Room Code** (contoh: `123456`).
Bagikan kode ini kepada para *hero* (peserta) agar mereka bisa bergabung ke dalam *party*.

</Step>

<Step>

### Mulai Sesi

Tunggu hingga semua peserta masuk ke dalam Tavern dan melengkapi *equipment* karakter mereka. Jika semua sudah siap, klik **START ADVENTURE** untuk memulai game.

</Step>

</Steps>

---

## Memantau Sesi (Saat Game Berlangsung)

Layar Host pada Zigma akan menampilkan peta dungeon, status *Health Point* (HP) monster atau boss, serta partisipasi anggota *Guild/Party*. Kamu bisa memandu peperangan dengan menjadi narator dari hasil jawaban benar pemain!
